Lean core·Oct 14

Lean v4.36.0 released with type class resolution caching across commands

The cross-command cache cuts type class resolution time on the standard library build by about 14% (Mathlib gains 0.2% overall). Other changes fix many grind bugs and several quadratic slowdowns (on a file with 4,000 definition/theorem pairs, elaboration time drops from 99 s to 32 s), and let def contracts state exception postconditions.

⊢Checked against: v4.36.0 release notes·lean4 v4.36.0

Verification·Nov 16

Harmonic's Aristotle now formally verifies Rust, joining C and Verilog

Harmonic says users can prove that Rust code has no undefined behavior and does exactly what its specification says, even if it uses unsafe, and that Rust code ported from C behaves the same as the original. The Lean account on X welcomed the use of Lean for Rust verification.

⊢Checked against: @HarmonicMath on X·@leanprover on X

Verification·Nov 16

Nockchain releases a Nock zkVM with an end-to-end Lean soundness proof

The Open Proof Machine's verifier checks a short proof instead of re-running a program in Nock, a tiny combinator language; kernel-checked soundness and completeness theorems cover all twelve opcodes, unbounded natural-number atoms and jets (known formulas that an interpreter replaces with native code). The alpha research release has not been independently audited.

⊢Checked against: nockchain.org·nockchain/nock-zkvm

Verification·Nov 16

Harmonic's Lean-powered Aristotle adds Rust verification alongside C and Verilog

Aristotle can prove that Rust code has no undefined behavior and does exactly what its spec says, even inside unsafe blocks (code the compiler does not check), and that C rewritten in Rust matches the original. On Manifest, an open-source Solana order book, Aristotle proved 28 results and found a rounding bug, since fixed.

⊢Checked against: harmonic.fun·leanprover.zulipchat.com

Verification·Nov 16

Aaron Elijah Mars verifies 15 Ethereum tokens' deployed bytecode in Lean 4

The proofs, 7,024 theorems in total, cover every input, caller and order of calls for tokens worth about $54 billion on Ethereum, including DAI, UNI, SHIB and PEPE. They show balances always add up to the total supply (or supply grows only as the rules say) and who can mint, freeze, blacklist or pause.

⊢Checked against: aaronjmars/proven-tokens

Verification·Nov 16

NyxFoundation publishes LeanAsm, a Lean 4 foundation for verified RV64 assembly

LeanAsm covers typed RV64IM (RISC-V) and scalar x86-64 assembly, executable machine semantics, encoding, and source emission; it is intended to be shared by ssz-asm, cl-asm, and p2p-asm. Its architecture follows the verified macro-assembly approach demonstrated by Verified-zkEVM's evm-asm while remaining independent of EVM, zkVM execution, and riscv-zkvm.

⊢Checked against: NyxFoundation/LeanAsm

Verification·Nov 16

OKcontract Labs releases Zean for proving Zig functions in Lean

The open-source toolkit translates supported Zig functions into executable Lean models, working from Zig's analyzed intermediate representation (AIR); an included copy-loop example proves its model avoids invalid accesses and uninitialized reads. Lean checks the translated model under its stated assumptions, so the proofs do not establish correctness of the final native binary.

⊢Checked against: okcontract.com
