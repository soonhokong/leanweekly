Troy Lee formalizes László Babai's graph isomorphism algorithm using an AI agent

With László Pyber's analysis replacing the classification of finite simple groups, the formalization proves that a single-tape Turing machine (Mathlib's Turing.TM0) decides whether two simple graphs are isomorphic within a quasipolynomial number of transitions. The agent (Claude Code, with Claude Opus 5.5) wrote the Lean code from 18 to 29 October 2026.

AI and formalization·Oct 29

Anthropic publishes Lean formalization of Claude's refutation of the Exponential Time Hypothesis

Anthropic's eth/ project, a machine-checked Lean 4 formalization, states that a single deterministic Turing machine counts the satisfying assignments of every k-CNF with at least two clauses on at least four variables, each of which occurs, within a step bound that refutes the hypothesis. Claude's paper is in the project folder.

Juan J. Manfredi completes Lean formalization of OpenAI's infinity-harmonic estimates

The formalization, built on Mathlib, proves the main results of OpenAI's 4 October 2026 preprint, including that infinity-harmonic functions (viscosity solutions of the infinity-Laplace equation) on connected open sets in dimensions 3 and higher are C¹, using only Lean's three standard axioms. Claude agents wrote the Lean proofs with Trellis, an AI-assisted formalization pipeline.

Leo de Moura speeds up kernel checking of lia and grind proofs

Lean's lia (cutsat) now shares proofs across grind case splits, for up to 2.8x faster elaboration and up to 200x faster kernel checking on goals with many case splits. Lean core·Oct 20

Sebastian Graf merged vcgen +jp, which verifies code after a split once

Without +jp, vcgen copies the code after an if or a match into every branch, so the number of copies doubles with each consecutive split. With +jp, VC generation grows linearly with the number of splits, and the shared code is verified under a hypothesis stating what each branch knows at its end.

⊢Checked against: lean4#14398

Papers and events·Oct 29

GenProof paper on verifying Minecraft redstone circuits uses Lean's bv_decide

Mike Murunov and Maksim Borisov's gate accepts a redstone layout only with a machine-checkable certificate of equivalence to its Verilog specification. Lean 4 re-proves the claim, unfolding it to one 4-bit equation per node and calling bv_decide, which bit-blasts, runs the CaDiCaL solver and checks its proof with a verified checker.

⊢Checked against: paper (pdf)
