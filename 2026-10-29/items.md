## Headlines

- **Troy Lee formalizes László Babai's graph isomorphism algorithm using an AI agent.** With László Pyber's analysis replacing the classification of finite simple groups, the formalization proves that a single-tape Turing machine (Mathlib's Turing.TM0) decides whether two simple graphs are isomorphic within a quasipolynomial number of transitions. The agent (Claude Code, with Claude Opus 5.5) wrote the Lean code from 18 to 29 October 2026.
