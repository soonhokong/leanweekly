Verification·Oct 23

Giulio rebuffo's Janus verifies compiled Go arm64 machine code in Lean 4

Janus, an early work in progress, decodes instructions in Lean and does not trust the Go compiler, linker, or any source-level reasoning. Every load and store must fall inside a caller-provided allocation, and Go runtime panic stubs (bounds checks, nil, divide) are named outcomes, so "this function never panics" is provable.

Verification·Oct 18

Ilya Sergey describes Vermilion, an experimental Lean backend for Rust verifier Verus

Vermilion expresses Verus's verification conditions (mathematical propositions about a program), normally sent to the Z3 solver, as Lean theorems, though it does not prove that they correctly describe Rust's semantics. Its default tactic, vrml, tries to prove each automatically, and any it leaves open can be proved interactively, drawing on Mathlib.
