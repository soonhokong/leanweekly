Verification·Nov 10

Google DeepMind uses AI agents to verify Signal's messaging security in Lean

The researchers used AlphaProof Code, a multi-agent framework for formal software specification and verification, on Signal's post-quantum PQXDH handshake and Triple Ratchet. The agents generated 6.5 million lines of Lean code proving the libsignal implementation correct against a human-reviewed specification; the proof assumes perfect cryptography.

Verification·Nov 2

Anthropic releases FlashProve, with Lean proofs of its security properties

Anthropic released FlashProve, which uses a zkSNARK (a type of cryptographic proof) to prove which AI model answered a request. Anthropic used Lean to specify FlashProve's protocol and prove completeness (honest proofs are accepted), soundness (fake proofs are rejected) and zero-knowledge (proofs hide the model's weights), and shipped an executable, provably correct Lean verifier.

⊢Checked against: anthropic.com·anthropics/FlashProve

Kiro proves properties of its own agent harness in Lean

Kiro wrote Lean models of 26 functions from its TypeScript, Rust, and Python harness (the code managing context, permissions, and state), proving 70 of 96 properties; 18 falsified ones reproduced on the real code. “Lean’s kernel checks every proof, the real code checks every finding,” says the post, which Swami Sivasubramanian shared on LinkedIn.

Verification·Nov 3

Jesse Comer and coauthors present Whiel for Lean-certified relational program verification

Whiel verifies programs whose states are database instances against Hoare specifications: an LLM proposes loop invariants, and the Vampire first-order theorem prover checks their verification conditions. An independent certifier constructs Lean proofs of the original specification or its negation; the 86 benchmark tasks have certified reference answers, 69 valid and 17 invalid.

Verification·Nov 3

Luk Koska, Tom Koska and Ben Koska verify GPU kernels in Lean

The authors formalize PTX, combining an interpreter covering 81 instruction forms with the axiomatic PTX memory model, and prove correct 9 hand-written PTX entry points (454 instructions), including simple implementations of FlashAttention and a 3-kernel MoE pipeline. LLM coding agents helped write the 34,034 lines of proof, which contain no sorry or custom axioms.

⊢Checked against: arXiv:2611.04447·paperswithlean.com

Verification·Nov 1

LARK verifies GPU kernels against PyTorch references using LLM agents and Lean

LARK formalizes a GPU machine model and per-operation semantics in Lean 4 once per target language (PTX, CUDA, HIP), and agents prove segment-by-segment equivalence under exact arithmetic. Of 10 production kernels from LLM serving frameworks, it verifies 9 and finds a previously unknown data race in the tenth, an llm.c softmax kernel.

Verification·Nov 2

Sreehari Sankar and coauthors present LeanGuard, Lean-verified guardrails for AI agents

LeanGuard checks every tool call an agent proposes against a Lean 4 policy, using a decision procedure proved equivalent to a LeanLTL temporal semantics. On Tau-Bench, unguarded Qwen agents executed at least 33 policy-forbidden calls while LeanGuard executed none, and it cut direct prompt-injection success on DTap from 57.9% to 5.9%.

⊢Checked against: arXiv:2611.02332·DebarghaG/LeanGuard

Verification·Oct 30

Jan Onderka, Armin Biere and Henrik Böving verify a Lean SMT-LIB parser

The paper introduces blazing-smtlib, a Rust parsing library for SMT-LIB (a standard input format for SMT solvers), and its Lean port BSmtLib, whose optimised lexer and parser provably match a formalised SMT-LIB syntax. On 9,201 benchmark files, blazing-smtlib is more than 6 times faster than previous libraries (geometric mean); BSmtLib is faster or comparable.

Verification·Nov 2

Sébastien Celles uses Lean 4 to find correctness bugs in Go

Inspired by julia-in-lean, the go-in-lean proof-of-concept models a bounded subset of Go (including all of math/bits), states each function's documented behaviour as a theorem, proves it with Lean's kernel and bv_decide, and turns failed proofs into Go tests. Counterexamples must reproduce in Go, and the README lists Go compiler bugs reported after human review.

⊢Checked against: s-celles/go-in-lean

On Ubuntu, lean-sudo reads the existing /etc/sudoers, /etc/sudoers.d and /etc/sudo.conf, uses the system's PAM stack, and passes the same 1113-test end-to-end suite as the original sudo, a large C program written around 1980 with a decades-long history of security bugs.

Verification·Oct 20

John Zhuoyang Ye and Jens Palsberg verify fault-tolerant quantum compilation in Lean

The paper introduces QPPM, a language for Pauli-product measurement programs, and verifies lowering of Clifford+T circuits to QPPM and an optimizer that eliminates measurements, fuses and reorders rotations, and schedules logical rounds. On QASMBench, verified fusion and scheduling reduce logical measurement depth by a median of 17.9%.
