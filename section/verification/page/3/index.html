Verification·Jan 29

Gavin Mendel-Gleason used GPT-5.2 and Lean to verify a citation-streaming program

Gavin Mendel-Gleason reports that opencode, GPT-5.2 and lean-lsp-mcp produced a provably correct citation streaming program for a RAG answering system in two hours with no interventions. Gavin Mendel-Gleason argues that LLMs increase software generation faster than software understanding, and calls the approach vericoding (vibe-coding using programme verification).

Verification·Jan 21

Ilya Sergey shows how to verify imperative Lean 4 programs with Velvet

A Proofs and Intuitions post walks through Velvet, a verifier embedded in Lean as a library and developed by VERSE Lab. Velvet discharges most proof obligations with SMT solvers (such as Z3 and cvc5) and tactics like grind, then leaves the rest for interactive proof. In the example, Claude Code and Harmonic's Aristotle each finished the remaining proof.

Verification·Dec 25, 2025

Logical Intelligence shares AI-generated verified λ-calculus to CPS compiler in Lean

Logical Intelligence posted on X an AI-generated, formally verified compiler from λ-calculus to CPS, written in Lean4. The post explains formal verification as code that comes with a mathematical proof, checked by the computer, that it works correctly in all cases, not just the ones tested.

Verification·Sep 18

Trail of Bits proves Miden core library arithmetic correct with AI-generated Lean proofs

During an audit of the Miden VM, a zero-knowledge VM with its own assembly language, Trail of Bits had agents build a Lean model of the VM executor, producing 95 correctness proofs covering all binary arithmetic components of the core library. The work identified two subtle bugs that the existing unit test suite did not catch.

Verification·Oct 15

Emina Torlak presents SymCert, a Lean framework for verified Cedar policy analyses

SymCert, implemented in Lean, builds verified SMT-based analyses of Cedar policies, an open-source authorization language. In the FMCAD 2026 paper, five analyses used in a Cedar analysis service at Amazon Web Services were modeled and proved in one work day, and three extensions for new Cedar features took 4 to 8 days each.

⊢Checked against: paper (pdf)

Verification·Oct 15

Flapjack ports the verified Pancake compiler from HOL4 to Lean

Flapjack is bringing the Pancake compiler, originally verified in HOL4, and its proofs to Lean, with a path compiling a fragment of Pancake to RISC-V where all stages except parsing and AST conversion have a correctness theorem. A MIPS32 backend targets the Ziren zkVM, but its output has been run only on Ziren's Lean model.

⊢Checked against: flapjack-lang.dev
