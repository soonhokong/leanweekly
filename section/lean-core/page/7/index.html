Lean core·Jan 22

Lean repository adds SymM symbolic simulation benchmark from Lean@Google Hackathon

A new benchmark in the lean4 test suite, described as a synthetic benchmark from the Lean@Google Hackathon, compares a MetaM tactic solution with SymM solutions, including a "SymM Solution + reusing simplifier cache" variant, on generated command sequences of up to 700 iterations, also timing kernel checking.

⊢Checked against: leanprover/lean4

Lean core·Jan 17

Leo de Moura adds ground evaluation and conditional rewriting to Sym.simp

Three merged Lean 4 pull requests by Leo de Moura extend Sym.simp: a simplification procedure evaluating ground terms of builtin numeric types such as Nat, Int and BitVec n, support for conditional rewriting rules, and offset terms, essential for equational theorems of functions that pattern match on natural numbers.

⊢Checked against: lean4#12031·lean4#12033·lean4#12053

Lean core·Jan 10

Sebastian Ullrich proposes bundling Lean's Init library into one .olean file

A pull request by Sebastian Ullrich bundles all Init module files into a single file with cross-sharing, reducing cumulative size from 325MB to 264MB and openat calls for import Init on Linux from about 2000 to about 80. The pull request is still open.

⊢Checked against: lean4#11965

Lean core·Jan 8

Leo de Moura removes super-linear kernel overhead in lambda simplification

A merged Lean pull request by Leo de Moura improves the proof term produced by mkFunext, which Sym.simp uses when simplifying lambda expressions. For a 200-lambda benchmark, kernel checking time fell from 148.681 ms to 6.903 ms, and the approach will later come to Meta.simp.

⊢Checked against: lean4#11932

Lean core·Dec 30, 2025

Leo de Moura adds benchmarks showing SymM beating MetaM on intros/apply

A merged Lean 4 pull request by Leo de Moura adds performance comparison tests between the new SymM monad and the standard MetaM for intros/apply operations. Results show a 10-20x speedup, rising from 10.8x at size 1000 to 22.0x at size 6000.

⊢Checked against: lean4#11838·leanprover/lean4
