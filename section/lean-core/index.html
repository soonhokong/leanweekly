Lean core·Oct 14

Joachim Breitner and Lean FRO describe the proof behind con-leche checker

con-leche, a checker for Lean 4, comes with a proof in Lean that every environment it accepts has a model in set theory, so no accepted environment holds a proof of False. A new document gives a pen-and-paper account of that argument on a simplified fragment of the checker.

⊢Checked against: leanprover.github.io

Lean core·Oct 13

Julia Markus Himmel reworks order instances across Lean core types

Julia Markus Himmel redefined the order on String as the lexicographic order of its UTF-8 encoding, made Min Float follow the IEEE-754-2019 minimum operation, and added missing order instances for BitVec, List, Array, Vector and ByteArray. Sofia Rodrigues fixed leaks and refactored the libuv bindings.

⊢Checked against: lean4#15581·lean4#15257·lean4#15274·lean4#15304·+3 more

Lean 4.35.0 ships vcgen, lake check, and bundled independent kernels

Lean 4.35.0, published on 2026-10-12, adds vcgen, a faster and more general successor of mvcgen, plus lake check and lake comparator, which check a project with Lean's kernel and optionally several independent kernels now included in the toolchain.

⊢Checked against: v4.35.0 release notes·lean4 v4.35.0

Lean core·Oct 12

Sebastian Ullrich removes Lean's 255-object-field limit per constructor

A merged pull request by Sebastian Ullrich removes the limit of 255 object fields per constructor, and thus per structure. When a constructor has more, the compiler keeps the first 254 in the constructor object and stores the rest in a chain of spill objects, with one pointer followed per spill object on access.

⊢Checked against: lean4#15516

Lean core·Oct 7

Lean reference manual documents vcgen, the successor of mvcgen in Lean 4.35

A pull request by Sebastian Graf documents the vcgen tactic and its Std.WP framework, adds the tutorial "Verifying Imperative Programs Using vcgen", and moves the mvcgen chapter and tutorial to their own files. The Kraken project already uses vcgen to prove that FFmpeg's FMA3 dot-product loop, over two arrays that may alias, terminates without faulting.

Lean core·Oct 4

Sebastian Ullrich makes Lean's type class resolution cache persist across commands

Two merged pull requests by Sebastian Ullrich keep type class resolution results for later commands and let queries differing only in free variables share a cache entry. Building Mathlib takes about 4% fewer instructions and 8% less wall-clock time, and spends about 16% less time in type class resolution.

⊢Checked against: lean4#14369·lean4#14316

Lean core·Sep 24

lazylean, a lazy-evaluation Lean kernel, competes in the Lean Kernel Arena

lazylean, a C++ type checker for Lean 4, hands computing terms to a Krivine machine with call-by-need thunks, after Coq's cClosure. The Lean Kernel Arena, which tests and benchmarks proof checkers for Lean, lists lazylean 0.3.0 alongside checkers such as tenet 0.11.1, lean4cobol and nanoclo-fortran.

⊢Checked against: corun1024/lazylean·arena.lean-lang.org

Lean core·Sep 24

Keith Adler releases Lean Studio, a native desktop IDE for Lean 4

Lean Studio runs on macOS, Windows and Linux and re-checks every declaration from the compiled .olean files with Tenet, a separate implementation of Lean's type checker. Keith Adler's IDE also includes Prove It, which tries 17 tactics on any sorry at once, and an MCP server for AI assistants.

⊢Checked against: keithadler/leanstudio

Lean core·Sep 23

Leo de Moura adds a polynomial arithmetic normalizer to Lean's Sym.simp

A series of merged Lean pull requests adds Sym.Arith.normalize?, which rewrites ring and semiring terms into polynomial normal form with a proof by reflection, and an arith simproc for Sym.simp that uses it. Later changes extend it to relations, ring characteristic, non-commutative rings, and some field rewrites, and grind's ring solver now shares Sym.Arith code.

⊢Checked against: lean4#15292·lean4#15279·lean4#15293·lean4#15295·+3 more

Lean core·Sep 21

Leo de Moura prototypes on-demand commutation theorems for state operations

Leo de Moura's Commute repository combines a simproc (a metaprogram that simp calls on matching subterms) with realizable constants, so only the pairs proofs use are ever proved, avoiding a quadratic table of lemmas. A related Lean pull request by Sebastian Ullrich adds Environment.realizationEnvContains.

⊢Checked against: leodemoura/Commute·lean4#15237

Lean core·Sep 17

Lean publishes hex, an aggregator for verified computational algebra libraries

The leanprover/hex repository bundles the released hex libraries for verified computational algebra in Lean 4, including LLL lattice reduction, integer polynomial factorization, graph canonical labelling via a formalization of nauty, and algebraic numbers. Each computational library is Mathlib-free, with Mathlib correspondence proofs in separate theory libraries.

Lean core·Sep 17

Lean FRO publishes con-ron, a Rust port of the con-leche checker

con-ron ports con-leche, an external Lean checker with a formal consistency proof, to Rust. It was written by AI under supervision from Joachim Breitner, and its Rust code is proven (partially) correct via an Aeneas-generated model, so checking a proof with both tools guards against compiler or runtime bugs.

⊢Checked against: leanprover/con-ron

Lean core·Sep 16

Lean FRO and SAIR Foundation launch Stage 1 of Lean Kernel Challenge

The multi-stage competition seeks faster algorithms for verified computation (using the Lean kernel to check computational results in a proof) across eight problems, including Fibonacci, prime counting, Rule 110, and SHA-256. Entrants prove each algorithm matches its specification; submissions close November 20, 2026.

⊢Checked against: terrytao.wordpress.com·competition.sair.foundation

Lean core·Sep 16

Robert Joseph George, Will Adkisson, Anima Anandkumar present FloatLib for Lean 4

FloatLib is a verified arbitrary-precision floating-point arithmetic library in Lean 4 that unifies IEEE binary and decimal arithmetic, arbitrary-width posits, P3109, and user-defined formats and rounding rules. Every certified backend is proved equal to a complete encoded specification, and the library, proofs, and benchmarks are released as open source.

⊢Checked against: arXiv:2609.19352

Lean core·Sep 14

Lean 4.34.0 fixes three kernel soundness issues found with AI testing

Lean 4.34.0, released 2026-09-14, fixes three soundness issues found with AI adversarial testing and adds defensive kernel checks. bv_decide gets integrated with sym and grind interactive modes and is up to six times faster, linters can carry state across commands, and lake lint gains a --code-quality mode emitting machine-readable JSON.

⊢Checked against: v4.34.0 release notes

Lean core·Sep 10

Joachim Breitner announces con-leche, a Lean checker proven consistent

con-leche is an external checker for Lean, proven in Lean never to accept a proof of False, implemented and proven by Claude (Fable and Opus) under heavy supervision by Joachim Breitner at the Lean FRO. On the FLT proof by Anthropic, it accepted 1,044,222 declarations in 2 h 22 min wall time.

⊢Checked against: leanprover/con-leche·leanprover.zulipchat.com
