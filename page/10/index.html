Lean core·Mar 27

Lean 4.29.0 released with a new extensible do elaborator

The release changes reducibility handling: isDefEq no longer bumps transparency when comparing implicit arguments, and a new @[implicit_reducible] attribute and a backward-compatibility option ease migration. It also adds grind support for higher-order Miller patterns, mvcgen support for specifications in the local context, and faster startup.

Lean core·Mar 9

Kyle Miller merges Lean syntax and structure default value changes

In Lean, structure field defaults can now depend on fields that come before and after them, and dotted function notation supports explicit mode (@.f) and explicit universes (.f.{u,v}). Field notation such as e.f.{u,v} now also accepts explicit universe levels, fixing a bug where levels were attributed to the wrong expression.
