AI and formalization·Apr 21

New arXiv papers test LLM formalization faithfulness, agents, and benchmarks in Lean

Kyuhee Kim, Auguste Poiroux and Antoine Bosselut evaluate GPT-5 and DeepSeek-R1 on 303 first-order logic problems: GPT-5 fabricates axioms during proof generation, while DeepSeek-R1 mistranslates premises. Other papers introduce PRIME, a benchmark of 156 theorems annotated in Lean 4, analyze tool-augmented formalization agents, and formalize the Wu-Ritt characteristic set method.

⊢Checked against: arXiv:2604.19459·arXiv:2604.19000·arXiv:2604.16538·arXiv:2604.14912·arXiv:2604.18882

Lean core·Apr 5

Kim Morrison splits Lean's implicit transparency level into implicit and instances

A merged pull request by Kim Morrison makes the transparency hierarchy none < reducible < instances < implicit < default < all, so @[implicit_reducible] annotations no longer have the side effects @[instance_reducible] has. A separate open pull request by Leo de Moura enables the backward.isDefEq.respectTransparency.types option by default.

Lean core·Apr 5

Leo de Moura proposes stricter transparency default for Lean's definitional equality checker

Leo de Moura opened a pull request enabling the backward.isDefEq.respectTransparency.types option by default, so the definitional equality checker respects the current transparency setting when matching metavariable types. The change prevents unintended unfolding of definitions and requires adding @[implicit_reducible] and @[expose] attributes to many library definitions.
