Lean core·Sep 23

Lean Workbench adds basic static Verso publications

A merged pull request by Jason Reed adds a Publish button to the project summary when a workbench-publication.json file configures Verso builds. Clicking it runs a Verso build and serves the result on a route extending the project URL. A follow-up makes publications create temporary directories in roughly the same way as tracked commands.

⊢Checked against: lean-workbench#139·lean-workbench#149

Lean core·Sep 18

Kim Morrison proposes supply-chain audits for Mathlib dependency updates

A Mathlib pull request by Kim Morrison adds a supply-chain audit step to the hourly update_dependencies.yml workflow, posting diffs, high-risk files touched and suspicious added lines for each changed dependency. The diffs come from paranoid-lake-update, which uses bare clones and git only, so nothing from upstream is executed.

⊢Checked against: mathlib4#43911
