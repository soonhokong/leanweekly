Carlo Ciliberto, Alessandro Rudi, Enrico Tassi introduce Proof-Carrying Contracts for AI agents

An execution system called the Airlock runs a tool call only if the Lean kernel accepts the agent's proof that the call preserves the agreed constraints in every case its model allows. A Lean 4 mechanization proves the constraints hold at every instant of execution, even for an adversarial agent, under stated assumptions.

Verification·Oct 23

Giulio rebuffo's Janus verifies compiled Go arm64 machine code in Lean 4

Janus, an early work in progress, decodes instructions in Lean and does not trust the Go compiler, linker, or any source-level reasoning. Every load and store must fall inside a caller-provided allocation, and Go runtime panic stubs (bounds checks, nil, divide) are named outcomes, so "this function never panics" is provable.

⊢Checked against: Giulio2002/Janus

Papers and events·Oct 22

Leo de Moura publishes MiniForth, a Lean tutorial for programming language semantics

MiniForth's Forth-inspired teaching language, whose programs act on a stack, has arithmetic, DUP, SWAP, DROP, calls, and conditionals. The tutorial embeds it as Lean functions (a shallow embedding) and as data (a deep embedding), proves program equivalences, and adds a second pass where grind handles routine reasoning; the build checks the examples and proofs.

Tanner Duve of Logical Intelligence offers Veil an invariant-synthesis tactic

Written for Veil, a Lean-based verifier for transition systems, #synthesize_invariants runs the universal PDR algorithm on a module and its safety property. Lean core·Oct 21

Leo de Moura adds three lia changes that avoid large case splits

The pull requests, merged October 20 and 21, add dynamic variable reordering before large Cooper splits (case splits with as many cases as a variable's coefficient), exact elimination of equations without unit coefficients, and divisibility normalization. Chains of such equations from / and % definitions no longer yield Cooper splits with thousands of cases.

⊢Checked against: lean4#15835·lean4#15838·lean4#15827

Lean core·Oct 22

Sebastian Ullrich proposes precomputed prefix trees to speed up Lean imports

The open pull request replaces hash maps of imported constants, built eagerly at import time, with per-module prefix trees precomputed when oleans are written and merged lazily on first access. The change cuts import Lean wall-clock time by 28% and Mathlib's import phase by 21%, in exchange for about 6% larger standard library oleans.

⊢Checked against: lean4#14362

Verification·Oct 21

Kraken Lean project proves FFmpeg's SBR decoder binary safe

The theorem sbr_session_safe covers the linked machine code (aacsbr.o with its callees): given the link's layout, external routines' contracts and a 32-bit bound on their stack, every run stays in the memory it owns and uses at most the stated stack. The prefix-code and bound facts of FFmpeg's Huffman tables are proved.

⊢Checked against: zrlk/kraken

Verification·Oct 18

Ilya Sergey describes Vermilion, an experimental Lean backend for Rust verifier Verus

Vermilion expresses Verus's verification conditions (mathematical propositions about a program), normally sent to the Z3 solver, as Lean theorems, though it does not prove that they correctly describe Rust's semantics. Its default tactic, vrml, tries to prove each automatically, and any it leaves open can be proved interactively, drawing on Mathlib.

⊢Checked against: proofsandintuitions.net·@ilyasergey on X
