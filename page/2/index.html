Papers and events·Oct 20

Carlo Ciliberto, Alessandro Rudi, Enrico Tassi introduce Proof-Carrying Contracts for AI agents

An execution system called the Airlock runs a tool call only if the Lean kernel accepts the agent's proof that the call preserves the agreed constraints in every case its model allows. A Lean 4 mechanization proves the constraints hold at every instant of execution, even for an adversarial agent, under stated assumptions.

AI and formalization·Oct 19

Matija Bucić, Fankang He and Hyunwoo Lee prove Erdős-Szemerédi sunflower conjecture

Posed in the 1970s, the conjecture bounds the size of any family of subsets containing no k-sunflower and was previously known only for k = 3, via cap-set results. According to paperswithlean.com, the proof was machine-verified in Lean 4, with the formalization to be released in the Palomar repository.

Aditya Ranjan Jha and coauthors mechanize a hardware type system in Lean

Pact, a typed extension of the Anvil hardware description language, checks each component against its type, and compatible types guarantee communication safety (no unsynchronized exchanges or loss of progress). The POPL 2027 paper's artifact includes a Lean 4 mechanization proving soundness of type inference, type checking, and compatibility, plus optimality of inferred types.

Lean core·Oct 19

Linux 7.3 works around AMD CPU bug behind Lean build segfaults

The FRO noticed probabilistic segfaults while compiling big Lean projects on certain AMD CPUs running Linux 6.15 or later, and reported them to the Linux kernel. Users of AMD Zen 5 CPUs on kernels 6.15 through 7.2 should consider kernel 7.3 and/or the latest AMD microcode, or, failing that, boot with the option tlbi=ipi.

⊢Checked against: leanprover.zulipchat.com·lore.kernel.org

Verification·Oct 18

Ilya Sergey describes Vermilion, an experimental Lean backend for Rust verifier Verus

Vermilion expresses Verus's verification conditions (mathematical propositions about a program), normally sent to the Z3 solver, as Lean theorems, though it does not prove that they correctly describe Rust's semantics. Its default tactic, vrml, tries to prove each automatically, and any it leaves open can be proved interactively, drawing on Mathlib.

⊢Checked against: proofsandintuitions.net·@ilyasergey on X

Verification·Oct 17

Anirudh Gupta, Siddhartha Gadgil and Petros Markopoulos present PastaLean for verifying Python

PastaLean deterministically translates Python into Lean through Python's abstract syntax tree, with no LLM, turning specifications written in Python into theorems for agents or humans to prove. It also includes TypeInfer, a Python type inference engine that completed one benchmark in 1.25 s against HeaderGen's 36.2 s, and an MCP server for coding agents.

⊢Checked against: anirudhg07.github.io·siddhartha-gadgil/PastaLean·leanprover.zulipchat.com

Lean core·Oct 12

Sebastian Ullrich removes Lean's 255-object-field limit per constructor

A merged pull request by Sebastian Ullrich removes the limit of 255 object fields per constructor, and thus per structure. When a constructor has more, the compiler keeps the first 254 in the constructor object and stores the rest in a chain of spill objects, with one pointer followed per spill object on access.
