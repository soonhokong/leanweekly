AI and formalization·Aug 4

Yueyang Feng, Ilya Sergey and coauthors present LeetProof for verified code generation

LeetProof is an agentic pipeline built on Velvet, a multi-modal verifier embedded in Lean, that generates a program, its formal specification, and a machine-checkable proof from a natural-language description. The paper, accepted to ASE'26, reports that property-based testing validates specifications before any code is synthesised.
