Leo de Moura presents scalable software verification in Lean at SViL 2026

At SViL 2026 at INRIA Paris on April 20, 2026, Leo de Moura presented SymM, a monad for symbolic simulation and VC generation (turning code and specifications into proof obligations). On one challenge it ran about 100× faster than MetaM, and a Velvet port beat Dafny on 24 of 27 benchmarks.

AI and formalization·Apr 25

Sidharth Hariharan, Maryna Viazovska and coauthors report on formalizing 8-dimensional sphere packing

The paper describes how Maryna Viazovska's 2016 solution of the sphere packing problem in dimension 8 was formally verified in Lean in February 2026, with the final stages done by Math, Inc.'s autoformalization model Gauss. It discusses the techniques used, the collaboration between humans and Gauss, and remaining project objectives.

⊢Checked against: arXiv:2604.23468

Alex Meiburg shares Aristotle-authored Z80 emulator with verified assembly GCD

Alex Meiburg asked Aristotle to formalize a Z80 emulator, build an assembler, and write a BigNum GCD in about 80 assembly instructions, then verify it by modeling the whole CPU execution. After 14 rounds of submitting to Aristotle (without editing the prompt), the proof succeeded.

Verification·Apr 30

Mark Ruvald Pedersen releases Clift, an AutoCorres-style C verification pipeline for Lean 4

Clift verifies C programs by lifting them into Lean 4, following the methodology pioneered by seL4's AutoCorres pipeline in Isabelle/HOL and adapting AutoCorres2's five-stage pipeline to Lean 4's type theory. The accompanying paper reports that Claude Opus 4.6 generated the vast majority of the code, with 1,698 theorems and 12 remaining sorry.

⊢Checked against: paper (pdf)·eisbaw/Clift

Lean core·Apr 29

Leo de Moura merges grind diagnostics, solver fixes, and a ring-degree limit

The new grind.ematch.diagnostics option tracks how E-matching theorem instances depend on each other, and a ringMaxDegree option (default 1024) bounds polynomial degree in the grind ring solver. Other merged pull requests fix beta reduction to respect the generation threshold, fix a kernel error for Nat casts to non-Int types, and extend the homomorphism demo.

Lean core·Apr 30

Joachim Breitner's experimental nanobruijn kernel type-checks all of Mathlib

nanobruijn, an experimental Lean 4 type checker in Rust forked from nanoda_lib, keeps expressions as pure de Bruijn indices with shift-homomorphic caching, and type-checks all of Mathlib (670k declarations) with 0 errors and 0 timeouts. The code changes were written by Claude (Anthropic), directed by Joachim Breitner.

⊢Checked against: nomeata/nanobruijn

Lake gains builtin environment linting through new lake lint flags

A pull request by Wojciech Różowski, merged on 2026-04-22, adds builtin environment linting support to Lake, accessible via lake lint flags such as --builtin-lint and --clippy. vscode-lean4 adds picker-based input method for Unicode abbreviations

A merged pull request by Marc Huisinga adds three commands (Find, Copy, and Insert Unicode Symbol) that search symbols by abbreviation or by symbol, making it easier to insert Unicode into non-editor dialogs. Copy and Insert are bound to Ctrl+Alt+\ depending on whether a text editor is focused.
