CSLib adds a fully verified proof of the FLP impossibility result

CSLib, the Lean Computer Science Library, now includes a proof of the FLP (Fischer, Lynch and Paterson) result: consensus is impossible in a distributed system with a faulty process and asynchronous messaging. Ching-Tsun Chou formalised the constructive pen and paper proof by Hagen Völzer from 2004.

AI and formalization·Aug 4

Yueyang Feng, Ilya Sergey and coauthors present LeetProof for verified code generation

LeetProof is an agentic pipeline built on Velvet, a multi-modal verifier embedded in Lean, that generates a program, its formal specification, and a machine-checkable proof from a natural-language description. The paper, accepted to ASE'26, reports that property-based testing validates specifications before any code is synthesised.

⊢Checked against: arXiv:2604.16584·lnkd.in

Verification·Jul 29

CircuitProver uses a Lean 4 agent to prove parameterized hardware designs correct

Ziyi Yang, Wenji Fang, Chen Chen, Zhiyao Xie, and Hongce Zhang present CircuitProver, an agentic Lean 4-based verification framework that translates hardware designs and natural language specifications into Lean 4 models and reuses verified lemmas across tasks. Across 63 tasks it proves all benchmarks, while a vanilla agent solves 92.1% of them.

⊢Checked against: arXiv:2607.27259
