## Headlines

- **Math, Inc.'s Gauss completes formal proof of sphere packing in dimensions 8 and 24.** Math, Inc. used Gauss to help formally verify Maryna Viazovska's Fields Medal-winning sphere packing results, proving all remaining 8-dimensional results in 5 days and autoformalizing the 24-dimensional case in two weeks. The formalization grew from 70k to about 200k lines. ([math.inc](https://www.math.inc/sphere-packing))

## Lean core and ecosystem

- **CSLib publishes contributor guide for formalizing computer science in Lean.** The CSLib contributing guide covers two pillars: formalising computer science as reusable infrastructure, and code reasoning about mainstream programming languages via Boole, intermediate representations, and VC generation. Contributors who use AI must explain which tools they used in the PR description, following the Mathlib policy. ([leanprover/cslib](https://github.com/leanprover/cslib/blob/main/CONTRIBUTING.md))
- **Lean publishes fifth release candidate for v4.29.0.** The Lean project published v4.29.0-rc5, the fifth release candidate for the v4.29.0 release of Lean, on GitHub on March 5, 2026. ([lean4 v4.29.0-rc5](https://github.com/leanprover/lean4/releases/tag/v4.29.0-rc5))
