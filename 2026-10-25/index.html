Lean core·Oct 25

Joachim Breitner releases con-agua, a Lean checker with verified x86 assembly

Written by AI under Joachim Breitner's supervision, con-agua is an x86 assembly port of the external Lean checker con-leche and requires the Kraken x86 semantics to be correct in place of the Lean compiler and runtime. A 5MB assembly file and a 200-line main.c, plus one data file, are all it needs.

⊢Checked against: leanprover/con-agua·leanprover.zulipchat.com

AI and formalization·Oct 20

Resolution uses Claude Fable 5.1 to formalize Hironaka's resolution of singularities

The library, written in Lean 4 over Mathlib, proves Hironaka's main theorems in characteristic zero and their refinements by Kollár, Włodarczyk and Bierstone–Milman, for algebraic schemes and analytic manifolds and spaces. Chris Elliott at Resolution directed and audited the automated formalization process, and the code is licensed under Apache License 2.0.

⊢Checked against: resolutionorg/hironaka·resolutionorg.github.io·reservoir.lean-lang.org

Verification·Oct 25

Miles Cranmer's AI agents model Julia code in Lean and find bugs

Lean definitions mirror Julia functions line by line, and each property ends proven, or refuted with a concrete counterexample and a pure-Julia reproducer. In Julia Base and several standard libraries, 400 of 910 properties were refuted and 75 issues filed on JuliaLang/julia; DynamicExpressions.jl, the expression-tree package behind PySR, merged 38 Lean-derived fixes.

⊢Checked against: MilesCranmer/julia-in-lean

Verification·Oct 21

AssureCode uses Lean for structured justification of AI-generated code

Logan Murphy and coauthors describe AssureCode, which autoformalizes developer intent into Lean specifications for human approval, then decomposes claims via Lean templates, with Lean checking an agent's decomposition-soundness proofs. On HumanEval, LiveCodeBench and MBPP samples with four LLMs, a single run recovered most of an iterative LLM baseline's concerns and surfaced additional ones.

⊢Checked against: arXiv:2610.29758·paperswithlean.com

Verification·Oct 21

Katzenpost's Lean library Cryptlib implements the Sphinx cryptographic packet format

Cryptlib's Sphinx packets are binary compatible with the Katzenpost mix network's Go implementation, including with a post-quantum/classical hybrid key encapsulation method (X25519 and ML-KEM-768) per hop. The AGPLv3-licensed library is for modeling protocols and proving their properties; each kind of primitive has a Lean structure with proposition fields that every instance must satisfy.

⊢Checked against: katzenpost/cryptlib·cryptlib.io·reservoir.lean-lang.org
