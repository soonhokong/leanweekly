AI and formalization·Sep 4

Anthropic's Claude formalizes a complete proof of Fermat's Last Theorem in Lean

Working largely autonomously over 11 days, Claude wrote 13 million lines of Lean (over 5x the size of Mathlib, the principal community library) and proved 29,500 intermediate theorems. Kevin Buzzard compiled the code and ran comparator on it, and the full proof is on GitHub with a written walk-through.

⊢Checked against: anthropic.com·xenaproject.wordpress.com·anthropics/fermats-last-theorem·nature.com

Lean FRO and SAIR Foundation launch Stage 1 of Lean Kernel Challenge

The multi-stage competition seeks faster algorithms for verified computation (using the Lean kernel to check computational results in a proof) across eight problems, including Fibonacci, prime counting, Rule 110, and SHA-256. Entrants prove each algorithm matches its specification; submissions close November 20, 2026.

Verification·Sep 10

Certora proves zlib's inflate_table memory-safe and terminating in Lean

In under two weeks, Certora built an experimental C-to-Lean pipeline and proved that the Clight (CompCert's C intermediate representation) model of zlib's 266-line inflate_table function is memory-safe and terminating. The proof, around 20,000 lines of Lean, was written almost entirely by LLMs, and the Lean kernel checked every step.

Lean core·Sep 10

Joachim Breitner announces con-leche, a Lean checker proven consistent

con-leche is an external checker for Lean, proven in Lean never to accept a proof of False, implemented and proven by Claude (Fable and Opus) under heavy supervision by Joachim Breitner at the Lean FRO. On the FLT proof by Anthropic, it accepted 1,044,222 declarations in 2 h 22 min wall time.

Lean core·Sep 7

Sebastian Ullrich logs build optimizations for Anthropic's Lean proof of Fermat's Last Theorem

On a 1,000-module slice, adopting the module system and import minimization cut task-clock to 3,268 s (down 63.1%) and wall-clock to 140 s (down 86.3%). Sebastian Ullrich also released the proof as a single 1.01 GiB .olean download that can be run through lean4export for external checkers.

⊢Checked against: hackmd.io·fermats-last-theorem export

Lean core·Aug 31

Arthur Adjedj proposes a renovation of the Lean kernel logic

A meta issue by Arthur Adjedj, worked out with @nomeata, plans kernel changes that move feature selection for inductives to the elaborator and aim for a decidable, transitive definitional equality algorithm. Recursive predicates like Acc would lose large elimination, and the kernel changes would ideally ship in a single release.

⊢Checked against: lean4#14977

Lean core·Sep 17

Lean publishes hex, an aggregator for verified computational algebra libraries

The leanprover/hex repository bundles the released hex libraries for verified computational algebra in Lean 4, including LLL lattice reduction, integer polynomial factorization, graph canonical labelling via a formalization of nauty, and algebraic numbers. Each computational library is Mathlib-free, with Mathlib correspondence proofs in separate theory libraries.

Lean core·Sep 17

Lean FRO publishes con-ron, a Rust port of the con-leche checker

con-ron ports con-leche, an external Lean checker with a formal consistency proof, to Rust. It was written by AI under supervision from Joachim Breitner, and its Rust code is proven (partially) correct via an Aeneas-generated model, so checking a proof with both tools guards against compiler or runtime bugs.
