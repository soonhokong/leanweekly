Lean core·Jun 19

Lean 4.33 gives Float a pure Lean model, making float proofs possible

Julia Markus Himmel added Float.Model, a pure Lean implementation of 64-bit floating-point numbers, and made Float a wrapper around it, so float operations are no longer opaque to the kernel while compiled code still uses native operations. Users can now prove 0.1 + 0.2 != 0.3 with rfl.

⊢Checked against: juliahimmel.de·lean4#14079·lean4#14091·lean4#14110

Lean core·Jun 19

Sebastian Graf ports mvcgen' to Std.Internal.Do and extends it to embedded languages

Sebastian Graf merged a port of the experimental mvcgen' tactic to the new Std.Internal.Do meta theory, where loop invariants no longer restate the exceptional postcondition. A follow-up extracts a WP type class from WPMonad, enabling verification of deeply embedded languages, tested on an IMP language whose WP instance has no accompanying WPMonad.

⊢Checked against: lean4#14080·lean4#14015

Lean core·Jun 19

Lean enables respectTransparency.types by default, a breaking change

Paul Reichert's merged pull request makes Lean compare metavariable types at implicit transparency instead of default, building on Kim Morrison's split of transparency into implicit and instances levels (merged on 2026-06-19). Some lemmas may stop applying in simp or grind; set_option backward.isDefEq.respectTransparency.types false restores the old behavior.

⊢Checked against: lean4#13895·lean4#13637

Lean core·Jun 25

Henrik Böving adds cost metrics for grind's e-matching graph

A merged Lean pull request by Henrik Böving adds optional diagnostics, enabled via grind.ematch.diagnostics, that flag instances with many direct follow-up children and instances that participated in a large, transitive closure of follow-up instances. The metric is based on the cost heuristic of smt-scope, and thresholds are configurable.

⊢Checked against: lean4#14118

Example uses include including one docstring in another and showing all currently-available instances of a class.

Lean core·Jun 20

Sebastian Ullrich speeds up Lean's test suite with shared header snapshots

A merged pull request lets about 389 elab tests that use import Lean reuse one pre-built snapshot, cutting CPU time by 26.0% (2222 s to 1645 s), with CI test wall-clock speedups of about 10-40% depending on platform. Related pull requests speed up .olean and snapshot serialization, one cutting snapshot save time by about 28%.

Lean core·Jun 18

Henrik Böving makes Lean's get_task_state_core thread safe

A merged pull request by Henrik Böving changes the m_imp field of lean_task to an atomic. get_task_state_core read m_imp to check whether a task had finished before taking the mutex, so that memory access was undefined behavior (UB).

⊢Checked against: lean4#14108

Lean core·Jun 15

Lake now deduplicates artifact transfers to and from its cache

A pull request by Mac Malone, merged into leanprover/lean4, has Lake deduplicate artifacts by their hash when uploading or downloading to the cache (for example in lake cache put or lake cache get). The change fixes possible errors when curl was asked to transfer to the same file or URL multiple times.
