Verification·May 5

Jonathan Protzenko uses Aeneas to verify bounds safety in jxl-rs

Jonathan Protzenko's case study uses Aeneas, a toolchain for verifying Rust programs through a functional translation to Lean, on jxl-rs, a Rust rewrite of the jpeg-xl codec. The proof shows an unchecked array access always stays within bounds and showcases recent Aeneas features, including official grind support and loop combinators.

⊢Checked against: jonathan.protzenko.fr

Lean core·May 7

Sebastian Graf merges experimental mvcgen' tactic into the Lean toolchain

The pull request adds mvcgen', reimplemented from the ground up on the new SymM-based framework for efficient symbolic evaluation. It will soon replace mvcgen and can outperform it by a factor of more than 100 on some synthetic benchmarks. Join point sharing and introduction of local specs are not yet supported.

⊢Checked against: lean4#13644

Lean core·May 1

Leo de Moura merges a series of grind fixes into Lean

The merged pull requests fix grind's AC invariants, a congruence-table panic, cast internalization order and missing proof hints. A new ringMaxDegree option (default 1024) bounds polynomial degree in the ring solver, and derived tactics such as lia, linarith and ring now fail quickly on out-of-scope problems.

⊢Checked against: lean4#13593·lean4#13585·lean4#13590·lean4#13624·lean4#13625·lean4#13623·lean4#13614·lean4#13622

Lean core·May 5

Leo de Moura fixes a panic and an assertion failure in Sym.simp

One merged Lean 4 pull request fixes a Sym.simp panic triggered when match reduction exposed kernel projection terms, for example in a do block with a for loop over tuple state. Another removes an incorrect assertion that failed on have-expressions whose binder type depends on an earlier binder.

⊢Checked against: lean4#13635·lean4#13611·lean4#13612

Mac Malone extends Lean-to-Python module initialization in Nerodia

Mac Malone's merged pull request lets a Lean-written initializer add a constant to the Python module, adds Lean-side argument validation, and adds a Lean-to-Python-to-Lean test. A second merged change splits the global Python state (g_py_main) from the per-use GIL context (py_context).

Lean core·Apr 28

Wojciech Różowski moves Batteries linters into Lean core and extends lake lint

Wojciech Różowski upstreamed the dupNamespace and unnecessarySeqFocus linters from Batteries to core Lean as "clippy" linters, which are disabled by default and run with lake lint --clippy. lake lint --builtin-lint now also supports text linters, and a new script reports deprecated modules, options and syntax usage.

⊢Checked against: lean4#13513·lean4#13538·lean4#13540·lean4#13586
