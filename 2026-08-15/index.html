AI and formalization·Aug 10

Claude raises Riemann zeta zero bound to 67.2%, formalized in Lean

An unreleased research version of Claude increased the lower bound for the fraction of Riemann zeta zeros satisfying the Riemann hypothesis from 41.6% to 67.2%. Claude and Eric Easley produced a Lean formalization that passes comparator, the validation tool originally developed by Lean FRO with feedback from the AIMO team.

⊢Checked against: anthropic.com·anthropics/zeta-23-lean·leanprover/comparator

Lean core·Aug 10

Lean 4.33.0 released with editor, tactic, Float, and kernel changes

Lean 4.33.0, published 2026-08-10, makes the editor more responsive, lets try? propose proofs on its own, improves the lia and grind tactics, and stops Float from being an opaque type. It also fixes kernel soundness bugs and enables backward.isDefEq.respectTransparency.types by default, the change most likely to need attention when porting.

⊢Checked against: v4.33.0 release notes·lean4 v4.33.0

Lean core·Aug 11

Kim Morrison releases an integer polynomial factorization library for Lean

The library, part of Hex, the computer algebra library for Lean, includes tactics for factorizing and irreducibility and implements van Hoeij's knapsack method, which according to Kim Morrison has never previously been formally verified. It builds on hex-lll, whose theory package proves that both lattice reducers satisfy their reducedness and lattice-preservation contracts.

⊢Checked against: LinkedIn post·leanprover/hex-lll

Verification·Aug 15

Predictable Machines builds Predictable Code on Lean 4, open-sources two libraries

Predictable Code uses Lean 4 formal verification to prove that AI-generated code matches specifications, and is currently in private beta. Predictable Machines also open-sourced lean4-json-schema, which derives JSON Schemas from types and proves at compile time that serialization always validates, and lean4-tree-sitter, typed bindings for tree-sitter.

⊢Checked against: predictablemachines.com·code.predictablemachines.com·predictablemachines.com·predictablemachines.com

Lean core·Aug 15

Guide explains how to validate and report Lean kernel soundness bugs

A "Kernel bug hunt" document explains what counts as a Lean kernel soundness bug and how to validate a candidate before reporting it, using lake check, comparator (the validation tool) or its web interface. Starting with Lean v4.35.0, the distribution bundles four additional kernels, two of them formally verified.

⊢Checked against: hackmd.io

Lean core·Aug 11

Sebastian Graf extends Lean's def contracts and vcgen loop verification

Merged pull requests let repeat and while loops state the invariant and termination measure that vcgen needs, so a loop inside a def with a contract verifies without manual proof steps. Other changes allow match alternatives in ensures clauses, invariants on destructuring for loops, and type ascriptions on contract binders.

⊢Checked against: lean4#14703·lean4#14701·lean4#14682·lean4#14686·+2 more

Lean core·Aug 15

Paul Reichert fixes instance search seeing through type synonyms in Lean

Paul Reichert's merged PR ensures that, during instance search, metavariables for instance-implicit arguments are only assigned values of the expected type, fixing an issue Sebastien Gouezel hit while formalizing Riemannian metrics in Mathlib. A preparatory PR brought a clear performance improvement with no Mathlib breakage observed. Affected Mathlib declarations were fixed with a backward compatibility option.

⊢Checked against: lean4#14624·lean4#14583·lean4#9077

Lean core·Aug 15

Lean releases Nerodia, a library for writing Python modules in Lean

Nerodia, a Lean/Python FFI library inspired by PyO3, uses Lake, Lean's build system, to build native Python modules in pure Lean and generates type stubs automatically. It is a work-in-progress with a very limited API, released primarily as a proof-of-concept and to obtain feedback on its design and build process.

⊢Checked against: leanprover/nerodia
