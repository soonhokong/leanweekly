How an item is made

A pipeline collects candidate news each day from GitHub, Hacker News, Mastodon, Bluesky, blogs, news search, the Lean Zulip, paper feeds, and registries. Each week it groups them into stories, fetches the public sources of each story, and writes a short item from those sources alone. A second check compares each statement in the item with the sources, and the editor reviews the items before they are published. Each item links to the public sources it was checked against.
